# 🔐 Security Basics

## The CIA triad
- **Confidentiality**: only the right people see the data
- **Integrity**: data isn't changed without permission
- **Availability**: systems work when needed

## Common threats
- **Phishing**: fake messages that steal your login
- **Malware**: harmful software (virus, ransomware, trojan)
- **Brute force**: guessing passwords again and again
- **SQL injection / XSS**: attacks on badly built websites

## Good habits
- Long, unique passwords + a password manager
- Turn on 2FA everywhere
- Update your system and apps
- Never click unknown links
